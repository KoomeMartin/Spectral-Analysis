# Lab 3 report (LaTeX)

- `main.tex`: the report (cover page, setup, Part I, Part II, summary, files). It uses the same template as the Lab 2 report.
- `images/`: the figures used by the report. File names start with the part they belong to.

| Image | Part | Source |
|---|---|---|
| `p1_cscale_N2048.png`, `p1_music_N128.png`, `p1_music_N16384.png` | I | copied from `Submission/` (saved from the app) |
| `p1_cscale_N256_N8192.png`, `p1_cscale_single_blocksize.png`, `p1_cscale_windows.png` | I | generated by `scripts/make_report_figures.py` |
| `p2_*` (audio: `cscale_*`, `music_*`) | II | generated: noisy file above, filtered file below, same settings and reference level |
| `p2_img_*` | II | generated from `data/` and `Submission/` |

Regenerate every generated figure and print the SNR and PSNR values quoted in the report, from the Lab 3 folder:

    python scripts/make_report_figures.py

Build (any TeX distribution, run from this folder):

    pdflatex main.tex
    pdflatex main.tex     # second run resolves figure and table references

Or upload the `latex/` folder to Overleaf and compile `main.tex`.
